# Pre-0.7.0 Audit Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix every finding of the 2026-10-04 pre-release audit so 0.7.0 ships with working docs, hardened client/error handling, validated builder options, a one-call streaming path and spec-complete OTel metadata.

**Architecture:** Four PRs, each on its own branch off `main`. PR A (client & errors) and PR B (request builder) touch disjoint files and can run in parallel. PR C (streaming & telemetry) starts after A merges (it uses `APIError.parse_type/1`). PR D (docs, packaging, release prep) runs last. Each PR adds CHANGELOG lines under `## [Unreleased]`; PR D folds `[Unreleased]` into `[0.7.0]`.

**Tech Stack:** Elixir ≥ 1.15, Req ~> 0.6 (≥ 0.6.1), Jason, :telemetry ~> 1.3, ExUnit + Bypass.

**Spec:** `docs/superpowers/specs/2026-10-04-pre-0.7-audit-design.md` (finding IDs C1…P6 below refer to it).

## Global Constraints

- Elixir floor `~> 1.15`: no `String.replace_invalid/1` (1.16+), no 1.16+ APIs.
- No new runtime dependencies.
- Option validation goes through `Claudio.Options.validate!(opts, allowed, "Module.fun/arity")` — error text format `"<fun>: unknown option :x; allowed: :a, :b"`.
- Value errors raise `ArgumentError` naming the function and the bad value: `"Request.set_temperature/2: temperature must be a number between 0.0 and 1.0; got 1.5"`.
- No per-model validation (the API's 400 is authoritative); pass new API values through verbatim.
- Every behavior change gets a CHANGELOG line under `## [Unreleased]` → `### Changed` / `### Added` / `### Fixed`.
- Commits: add files individually (never `git add .`); end messages with the session's attribution lines.
- Each PR is green on `mix precommit` and `mix docs --warnings-as-errors` before it's opened.

### Task A2: Honour Retry-After on 429/503/529, with or without `delay:` (C2)

**Files:**
- Modify: `lib/claudio/client.ex` (`req_retry_options/1`, `retryable?/2`, moduledoc "Retries")
- Test: `test/client_test.exs`

**Interfaces:**
- Consumes: validated `retry_opts` from A1.
- Produces: `retryable?/2` keeps its public `@doc false` boolean contract (existing tests call it); a new private `retry_decision/3` returns `false | {:delay, ms}`.

Design: Req only reads Retry-After on 429/503 and skips it when `:retry_delay` is set. Claudio stops passing `:retry_delay` and instead has its `retry:` fun return `{:delay, ms}` for every retryable outcome: the Retry-After value (integer seconds; HTTP-date or garbage → fall back) on 429/503/529, else the backoff — configured `delay * 2^attempt` capped at `max_delay`, or Req's default schedule `1000 * 2^attempt` (Req's `exp_backoff_with_jitter` minus jitter) when `delay:` is unset. The attempt number is `Req.Request.get_private(request, :req_retry_count, 0)`.

- [ ] **Step 1: Write the failing tests** — a Bypass server answering N retryable responses then a 200, measuring the gap with `System.monotonic_time(:millisecond)` stored in an Agent. defp measure_retry_gap(status, headers, client_opts) do
```elixir
  bypass = Bypass.open()
  {:ok, times} = Agent.start_link(fn -> [] end)

  Bypass.expect(bypass, "POST", "/messages", fn conn ->
    Agent.update(times, &[System.monotonic_time(:millisecond) | &1])

    if length(Agent.get(times, & &1)) == 1 do
      conn = Enum.reduce(headers, conn, fn {k, v}, c -> Plug.Conn.put_resp_header(c, k, v) end)
      Plug.Conn.resp(conn, status, "")
    else
      conn
      |> Plug.Conn.put_resp_content_type("application/json")
      |> Plug.Conn.resp(200, Jason.encode!(ok_message_body()))
    end
  end)

  client =
    Claudio.Client.new(
      Map.new([token: "t", version: "2023-06-01"] ++ client_opts),
      "http://localhost:#{bypass.port}/"
    )

  request = Request.new("x") |> Request.add_message(:user, "hi") |> Request.set_max_tokens(8)
  assert {:ok, _} = Claudio.Messages.create(client, request)
  [second, first] = Agent.get(times, & &1)
  second - first
end
```

```elixir
defp req_retry_options(opts) do
  [
    retry: fn request, response_or_exception ->
      retry_decision(request, response_or_exception, opts)
    end,
    max_retries: Keyword.get(opts, :max_retries, 3)
  ]
end

@retry_after_statuses [429, 503, 529]

defp retry_decision(request, response_or_exception, opts) do
  if retryable?(request, response_or_exception) do
    attempt = Req.Request.get_private(request, :req_retry_count, 0)
    {:delay, retry_after_ms(response_or_exception) || backoff_ms(attempt, opts)}
  else
    false
  end
end

defp retry_after_ms(%Req.Response{status: status} = response)
     when status in @retry_after_statuses do
  with [value | _] <- Req.Response.get_header(response, "retry-after"),
       {seconds, ""} when seconds >= 0 <- Integer.parse(String.trim(value)) do
    seconds * 1000
  else
    _ -> nil
  end
end

defp retry_after_ms(_other), do: nil

defp backoff_ms(attempt, opts) do
  case Keyword.get(opts, :delay) do
    nil -> 1000 * Integer.pow(2, attempt)
    delay -> min(delay * Integer.pow(2, attempt), Keyword.get(opts, :max_delay, 10_000))
  end
end
```

```elixir
@doc """
Consumes a streaming response in one pass and returns the final `Claudio.Messages.Response`.

The simplest way to stream: print text as it arrives and still get `usage`,
`stop_reason` and tool calls at the end.

    {:ok, response} =
      Claudio.Messages.Stream.to_response(stream_response, on_text: &IO.write/1)

    response.usage.output_tokens

## Options

- `:on_text` — called with each text delta, in order.
- `:on_event` — called with each parsed event (`{:ok, event} | {:error, reason}`).

A streaming body can be read **once**, and only by the process that called
`Claudio.Messages.create/2`: a second read waits forever, and a read from another
process raises. Use `:on_text` / `:on_event` instead of enumerating the response twice.

An SSE `error` event is returned as `{:error, %Claudio.APIError{}}`; other failures are
as for `build_final_message/1`.
"""
@spec to_response(Req.Response.t() | Enumerable.t(), keyword()) ::
        {:ok, Response.t()} | {:error, term()}
def to_response(source, opts \\ []) do
  opts = Claudio.Options.validate!(opts, [:on_text, :on_event], "Stream.to_response/2")
  on_text = Keyword.get(opts, :on_text)
  on_event = Keyword.get(opts, :on_event)

  source
  |> parse_events()
  |> Elixir.Stream.each(fn event ->
    if on_event, do: on_event.(event)
    if on_text, do: maybe_text(event, on_text)
  end)
  |> build_final_message()
  |> case do
    {:ok, message} -> {:ok, Response.from_map(message)}
    {:error, %{"type" => "error"} = data} -> {:error, Claudio.APIError.from_response(200, data)}
    {:error, _} = error -> error
  end
end

defp maybe_text({:ok, %{event: "content_block_delta", data: %{"delta" => %{"type" => "text_delta", "text" => text}}}}, fun)
     when is_binary(text),
     do: fun.(text)

defp maybe_text(_event, _fun), do: :ok
```
