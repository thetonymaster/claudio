# Pre-0.7.0 audit remediation — design

Date: 2026-10-04. Source: five parallel audits of `a9dff4b` (ergonomics, telemetry/OTel,
release hygiene, correctness since v0.6.0, API fidelity). Baseline at audit time: 789 tests,
0 failures; credo, dialyzer, `docs --warnings-as-errors`, `hex.audit` all clean.

## Scope decisions (Q, 2026-10-04)

- 0.7.0 ships everything merged through #30 **plus** every audit fix below, including the
  polish items. `[Unreleased]` is folded into `[0.7.0]`, dated the publish day.
- New API features are **out**: mid-conversation tool changes, inline tools, MCP tool-list
  pinning, Admin rate-limit / workspace-member endpoints → future specs S16–S19.

## Findings to fix (ID → owner PR)

### Client & errors (PR A)
- C1 `retry:` values unvalidated (`delay: "1s"` → ArithmeticError inside `create/2`;
  `max_retries: -1` silently = 0).
- C2 Retry-After ignored when `delay:` is set, and never read on 529 (Req reads it only on
  429/503 — `deps/req/lib/req/steps.ex:1824-1834`).
- C3 `version: nil` sends no `anthropic-version` header.
- C4 `Client.new/2`: `token: nil` accepted (no auth header); unknown keys accepted
  (`timeout_ms:`); `api_key:` → MatchError; keyword list → BadMapError.
- C5 `APIError`: JSON body without `error.type` ignores HTTP status; `request_too_large`,
  `billing_error`, `timeout_error` stay strings; non-UTF-8 body leaks into `message`.
- C6 `Batches.wait_for_completion/3` and `list/2` opts unvalidated; moduledoc calls a
  non-existent `/4` and uses ms for a seconds option.
- C7 `Files.upload/3`: no `expires_in_seconds` (GA 2026-08-19; placement to confirm).
- C8 Client docs teach obsolete `prompt-caching-2024-07-31` header.

### Request builder (PR B)
- B1 Unvalidated opts: cache `ttl` (any value / misspelled key), `add_message_with_document`
  opts, `Agent.run/4` opts.
- B2 Bare `FunctionClauseError` for common mistakes: `add_message(:system, …)`, string role,
  `set_temperature(1.5)`, `set_max_tokens("1024")`, `set_tool_choice("auto")`,
  `add_tool(keyword)`, `enable_thinking(keyword)`, `Tools.define_tool(atom, …)`.
- B3 `add_message_with_image/5` 5th arg positional (keyword silently becomes media_type);
  `add_message(:user, nil)` sends `content: nil`.
- B4 Sonnet 5.5: no `between_tools` thinking (release notes 2026-09-28); `set_tool_choice`
  doc omits Sonnet 5.5.
- B5 Web tools: no `response_inclusion` option (`web_search_20260318` / `web_fetch_20260318`),
  no `allowed_callers` passthrough on the web helpers.
- B6 `add_text_editor_tool/2` cannot emit `text_editor_20250124`.
- B7 Polish: `Response.get_text/1` rejects the legacy string-keyed map;
  `Tools.create_tool_result_message/1` is the identity (deprecate); `Agent.run` 4-tuple
  errors and swallowed handler crashes are undocumented; cache option naming (`ttl:` vs
  `cache_control:`) undocumented.

### Streaming & telemetry (PR C; after PR A)
- S1 Stream to text+usage takes 5 steps; `build_final_message/1` returns a raw map. Add
  `Stream.to_response/2` → `{:ok, %Response{}} | {:error, term}` with `on_text:`.
- S2 Consume-once / owner-process rule undocumented (second consumption hangs forever).
- S3 Stream SSE `error` gives string `error_type`, `create` gives atoms.
- T1 Guide's OTel `:exception` handler mis-records Erlang errors (needs `Exception.normalize/3`).
- T2 Missing `output_type` (→ `gen_ai.output.type`) and `stop_sequences`
  (→ `gen_ai.request.stop_sequences`) in create/count_tokens `:start` metadata.
- T3 Guide: context propagation into Tasks, `traceparent` via a Req request step,
  never-consumed stream emits no span, mid-stream raise reports `:halted`.
- T4 Tests: Erlang-error `:exception`, `count_tokens :exception`, non-owner consumer,
  crashing handler leaves request intact, never-consumed stream.
- T5 CI check that runs the guide's OTel handler.
